Política de privacitat de Conan

Darrera actualització: 4 d'octubre de 2026.

Conan és una aplicació d'ús personal de Josep Puigdevall Galceran. L'únic compte de Google al qual accedeix és el seu.

  • Què llegeix: els correus del compte de Gmail del propietari, per ordenar-los i preparar-ne respostes.
  • Què fa: llegir correus, crear esborranys i treure correus de la safata d'entrada (arxivar). No esborra correus.
  • On es guarda: les dades es processen als ordinadors del propietari. No es venen, no es cedeixen a tercers i no s'utilitzen per a publicitat.
  • Revocar l'accés: en qualsevol moment, a myaccount.google.com/permissions.

L'ús de les dades rebudes de les API de Google s'ajusta a la Google API Services User Data Policy, inclosos els requisits de Limited Use.

Contacte: joseppuigdevallgalceran@gmail.com

English. Conan is a personal-use application of Josep Puigdevall Galceran and only accesses its owner's own Google account. It reads Gmail messages, creates drafts and archives messages (removes them from the inbox); it does not delete messages. Data is processed on the owner's own computers, is never sold or shared with third parties and is never used for advertising. Access can be revoked at any time at myaccount.google.com/permissions. Conan's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
